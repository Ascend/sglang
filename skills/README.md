# SGLang Skills

This directory contains reusable skills for AI-assisted SGLang development.

## Available skills

- [`sglang-npu-adapter`](./sglang-npu-adapter/): guides model adaptation, debugging, validation, and precision root-cause analysis for running SGLang models on NPU devices.

The `sglang-npu-adapter` package provides platform-specific materials for Claude Code, OpenCode, and Trae. See its [README](./sglang-npu-adapter/README.md) for installation and usage instructions.
